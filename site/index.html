The problem

Reference formatting is not the hard part of a doctorate. It is just the part that never ends.

Most doctoral candidates do not lose weeks because their argument is weak. They lose them because reference managers emit a slightly different style on every machine, because a supervisor wants sentence case and the database exported Title Case, and because the dissertation template disagrees with the journal you are also submitting to. None of that is intellectual work, but all of it has to be right before anyone reads the argument.

This site exists for that narrow, unglamorous gap. Each tool does one mechanical job and shows you exactly what it did, so you stay in control of the scholarly decisions. The guides explain the rule behind the output, because a tool you cannot verify is a tool you cannot defend in a viva.

A note on accuracy. These tools implement the common APA 7 patterns for six source types. They are a formatting aid, not a style authority. Always check the current Publication Manual of the American Psychological Association (7th ed.), your institution's dissertation template, and your target journal's author guidelines. Where they conflict, the institution or journal wins.

APA 7 reference builder

Turn author names, dates and source details into a correctly structured APA 7 entry for journal articles, books, chapters, web pages, theses and conference papers. Handles initials, the 21-author rule, and DOI normalisation.

Reference list auditor + smart import

Flag fourteen recurring APA 7 mistakes line by line, with the reason for each flag. Smart import also rebuilds messy references copied from PDFs, Word files or a reference manager into structured APA 7 entries.

New: smart import recovers authors, dates, volumes, pages and DOIs from inconsistent input — including full-width punctuation and missing commas — without rewriting your titles or sending anything to a server.

Privacy

Your draft stays on your device

Both tools are written in plain JavaScript and execute entirely in the browser. There is no server-side component, no analytics script at launch, and no form submission of anything you type. You can confirm this yourself: open the browser's network panel while using a tool, or disconnect from the network entirely and reload the page — the tools keep working.
